About the project

October 2026

Visual Sentinel began as a senior project in the Department of Computer Engineering and Computer Science at the German Jordanian University, and grew into a funded research platform with two generations of hardware, a field archive, and the simulation work presented here.

Team

Students
Muthana Alhawamdeh, Mohammad Yasin, Osama Abbad, Hamza Salameh
Supervisors
Dr. Abdullah Alfarrarjeh and Dr. Amani Abu Jabal
Institution
School of Electrical Engineering and Information Technology, German Jordanian University, Amman
Support
King Abdullah II Fund for Development (KAFD), which financed the stations' hardware and supported the project through procurement and guidance; the second-generation experiments were flown at the KAFD field site
Collaboration
Jordan Design and Development Bureau (JODDB), for drone flights and controlled tests

The generation-1 project report, Visual Sentinel (German Jordanian University, 2025), is the source for that generation's hardware description and field campaign. The generation-2 rig, its orchestration software and the 107-experiment archive are the work of the extended team in 2025–2026. The simulator, the solvers and this website were developed to validate both designs and to plan the next phase.

Reproducing the results

Everything on this site that is simulated can be rerun. The simulator is a Python package with Blender as the renderer; the interactive viewers and this website are generated from the same scenario files.

pip install numpy opencv-python pyproj scipy pytest
python -m pytest -q                                       # geometry and solver tests (incl. the rig solvers)
python -m vsim.run scenarios/rig_verged.json              # Blender twin of the archive's B20 H75 D100 F210 rig
python experiments/rig_sweep.py                           # Results, Table 1 (verged rig)
python experiments/noise_sweep.py                         # Results, Table 2 (independent stations)
python -m vsim.export_viewer scenarios/rig_verged.json    # the interactive simulator page
python site/build.py                                      # this website

Scenario files are plain JSON: cameras with a position, a look_at point or heading and pitch, and either calibrated \(K\) matrices or a lens focal length; targets with a static position or a flight path. Adding a page to this site is one HTML file and one line in the navigation list; the site is static and can be hosted anywhere.
