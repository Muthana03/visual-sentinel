# Visual Sentinel — project website

Optical localization of airborne objects: a multi-camera drone-localization research
project at the German Jordanian University, funded by KAFD.

**Live site: https://muthana03.github.io/visual-sentinel/**

This repository holds only the built HTML. The pages are written and built in the
simulator repository (`site/src` + `python site/build.py`) and pushed here with
`python site/deploy.py`. Do not edit files here by hand; the next deploy overwrites them.
